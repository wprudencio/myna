# Configuration

Myna reads `~/.myna/config.json` at launch. The file is optional; Myna uses the
defaults below when it is missing.

```json
{
  "hotkey": "ctrl+alt+space",
  "sounds": true,
  "warmSeconds": 120,
  "recorder": null
}
```

Quit Myna from the menu and open it again after changing the file. There is no
in-app preferences window in this release.

## Shortcut

`hotkey` uses `ctrl`, `alt` (or `option`), `shift`, and `cmd` (or `command`), plus
one key.

```json
{ "hotkey": "cmd+shift+space" }
```

Supported keys: `space`, `return`, `enter`, `tab`, `escape`, `left`, `right`,
`up`, `down`, letters, digits, `F1`–`F12`, and common punctuation.

The shortcut must include **Ctrl**, **Option**, or **Command**. Shift alone is
not allowed because it would fire while you type capitals.

If the new shortcut is unavailable, the menu shows a warning. Choose another one
and reopen Myna.

## Microphone warm time

```json
{ "warmSeconds": 120 }
```

- `120` — keep the microphone warm for two minutes after a dictation (default)
- `0` — release it immediately after every dictation
- `-1` — keep it warm until you quit or choose **Release Microphone**

The orange microphone indicator in the menu bar is visible while it is warm.

## Sounds

```json
{ "sounds": false }
```

The menu's **Sounds** item overrides this for the current user. The menu choice is
remembered by macOS.

## Custom recorder (advanced)

`recorder` can replace the built-in microphone helper with any command that writes
**signed 16-bit little-endian, 16 kHz, mono** PCM to stdout.

```json
{ "recorder": "sox -d -t raw -r 16000 -e signed -b 16 -c 1 -" }
```

This is useful for audio interfaces or virtual devices with unusual formats. The
command must keep running while you record and exit when it is killed. Leave the
field as `null` to use the built-in helper.

## Files in `~/.myna`

| File | Purpose |
| --- | --- |
| `config.json` | The settings above |
| `menubar.json` | Generated by the app; do not edit |
| `daemon.json` | Live status and PIDs for this launch |
| `daemon.log` | Diagnostic log |
| `history.json` | The last 100 transcripts |
| `models/` | Parakeet Redux files |
| `bin/` | Only used by development builds; the packaged app uses its bundled helper |

If `config.json` is not valid JSON, Myna falls back to the defaults and logs the
problem. Delete the file to start over.

## Reset

To reset the model only:

```bash
rm -rf ~/.myna/models
```

Then reopen Myna; the model downloads again. To reset everything, quit Myna and
remove the whole `~/.myna` directory.
